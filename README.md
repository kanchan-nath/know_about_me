# Now_Myself 🚀
> Single Source of Truth Context Hub for Kanchan Nath

`Now_Myself` stores Kanchan Nath's developer bio, skill levels, project history, publications, and weekly progress in one version-controlled repository. All AI agents (Claude, ChatGPT, Cursor, Antigravity) fetch up-to-date context from this single source of truth.

---

## 📁 Repository Structure

```
Now_Myself/
├── data/
│   ├── profile.json       # Bio, education, contact, coding preferences
│   ├── skills.json        # Languages, backend, frontend, queues, databases, AI
│   ├── projects.json      # StudeQ, Nexus, YouTube backend, ScanBeforeEat, etc.
│   ├── experience.json    # Work history (Founder @ StudeQ, Outlier AI)
│   └── articles.json      # Hashnode published technical architecture articles
├── updates/
│   └── weekly.md          # Weekly notes, current focus, what you built
├── context/
│   └── full_profile.md    # Compiled markdown (auto-generated by build script)
├── dist/                  # Static site & JSON API for GitHub Pages
├── mcp/
│   └── server.py          # FastMCP server for Cursor, Claude Desktop, Antigravity
├── prompts/               # Ready-to-use setup guides for each agent
│   ├── cursor.md
│   ├── claude.md
│   ├── chatgpt.md
│   └── antigravity.md
├── scripts/
│   └── build.py           # Compiles JSON/MD into context files and static site
├── .github/workflows/
│   └── deploy.yml         # Auto-deploys to GitHub Pages on every push
├── llms.txt               # Standard LLM discovery file
└── README.md
```

## ⚡ Quick Start

### 1. Build Context Files
Run the build script to compile everything:
```bash
python3 scripts/build.py
```

### 2. Push to GitHub (Public)
```bash
git add .
git commit -m "feat: complete single source of truth for Kanchan Nath"
git branch -M main
git remote add origin https://github.com/kanchan-nath/Now_Myself.git
git push -u origin main
```

### 3. Enable GitHub Pages (Free Hosting)
1. Go to repository **Settings** -> **Pages**.
2. Under **Build and deployment** -> **Source**, select **GitHub Actions**.
3. Now your profile is live at `https://kanchan-nath.github.io/Now_Myself/`!

## 🔄 Weekly Update Workflow
1. Open `updates/weekly.md`.
2. Add what you built, learned, and are currently focused on.
3. Run `python3 scripts/build.py` and push to GitHub.
4. All agents immediately see your latest updates!
